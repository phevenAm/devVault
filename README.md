# devVault

A simple app for saving the things I keep learning and want to come back to later.

This project is meant to be a fast, personal reference space for notes, reminders, and useful snippets that I know I will revisit.

## What it is for

- Capture key takeaways from projects, tutorials, or problem-solving sessions
- Keep important notes easy to find later
- Use it as a lightweight personal knowledge base

## Tech stack

- React
- Vite
- Firebase

## Getting started

Install dependencies and start the app locally:

```bash
npm install
npm run dev
```
